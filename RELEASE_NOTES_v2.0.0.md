# Anyadha PMO v2.0.0

## Major release
This release expands the PMO foundation into an enterprise governance and management layer covering:
- Governance and Board management
- Delegation/approval architecture
- Strategy and portfolio
- Proposal/DPR
- Programme/project management
- Monitoring & Evaluation
- Grants and donor governance
- CSR governance
- Risk and internal controls
- Compliance and regulatory registers
- Audit and assurance
- SOP/document control
- KPI/KRI/KCI and MIS

## ERPNext integration
The app intentionally links to native ERPNext objects for accounting, procurement, HR, inventory, assets and transaction processing instead of duplicating those engines.

## Validation status
The included validator performs static package/DocType validation. Runtime validation still requires a real Frappe/ERPNext v16 site.
