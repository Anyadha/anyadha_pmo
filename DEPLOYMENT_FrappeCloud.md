# Frappe Cloud deployment

1. Push the repository to GitHub.
2. In Frappe Cloud, add the GitHub app repository.
3. Select the v2.0 release branch/tag.
4. Install on the existing ERPNext v16 site.
5. Run migrate/build.
6. Verify modules and DocTypes.
7. Execute UAT checklist before production use.

This app is designed for ERPNext v16 and should be tested on a non-production site first.
